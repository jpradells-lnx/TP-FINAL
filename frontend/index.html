Beneficios de acceder a turnos online

  • Sacar turno desde donde estés
  • Evita las colas para acceder a turnos, el traslado y costos de transporte
  • Disminución del tiempo de espera

¿Cómo saco turno?

Para sacar un turno online, sigue estos pasos:

  1. Ingresa a la pestaña "Saca turno"
  2. Selecciona la especialidad que necesitas
  3. Elige un horario disponible
  4. Confirma tu turno
